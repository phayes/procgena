# Texture licences

These textures were downloaded by hand from [3dtextures.me](https://3dtextures.me)
at 1024 × 1024 pixels. `textures convert` converts them to KTX2, a file
format for compressed GPU textures, and `textures images` writes JPEG copies
for exported models. The 2k versions are enlarged and the 512 versions
reduced copies. The source licence below applies to these converted files.

KTX2 files are named `cap/<id>-<size>-<map>-<format>.ktx2`, and JPEG files
`images/cap/<id>-<size>-<map>.jpg`.

All sets are released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) (public
domain). Attribution is not required but is given as a courtesy.
