# Texture licences

These ground textures come from [Poly Haven](https://polyhaven.com) and
[ambientCG](https://ambientcg.com). `textures fetch` downloads each set at
2048 × 2048 pixels, and `textures convert` converts them to KTX2, a file
format for compressed GPU textures, at 1k, 512 and 128 pixels. The source
licences below apply to these converted files.

KTX2 files are named `<category>/<id>-<size>-<map>-<format>.ktx2`, where the
category is `soil`, `litter`, `moss` or `rock`. The tables below list each set
by its id.

All sets are released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) (public
domain). Attribution is not required but is given as a courtesy.
