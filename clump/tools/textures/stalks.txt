# Stalk card textures: transparent images of twigs, sporophytes and similar
# shapes that stick out of clumps. Each card stands upright, with the stalk
# bases at the bottom centre of the image.
#
# One texture per line:
#   <kind> <source> <path> <title>
# Use kind in the clump stalk options and output file names. Paths are relative
# to prior_art/ (or the folder passed to the scripts). The title is the rest of
# the line and may contain spaces.
#
# Sources and setup:
#   nobiax     Colour and normal maps from Nobiax's "Free 3D branches textures"
#              pack 04 (CC0, https://nobiax.deviantart.com). Extract the pack's
#              .7z into prior_art/, keeping the folder paths below. Each texture
#              folder contains diffuse.tga (colour with transparency) and
#              normal.tga (lighting detail, OpenGL +Y).
#   generated  Images made for this project, saved in prior_art/<path>.png
#              (colour with transparency) and, when available,
#              prior_art/<path>-normal.png (OpenGL +Y). See LICENSE.md.
#              The sporophyte cards were cut out of AI-generated photos with
#              tools/textures/key_card.py:
#                key_card.py prior_art/sporophytes/source_<name>.png \
#                    prior_art/sporophytes/sporophyte_<name>
#
# Blank lines and lines starting with # are ignored.
