# Texture licences

The bark and end-grain textures come from [ambientCG](https://ambientcg.com)
and [Poly Haven](https://polyhaven.com). `textures fetch` downloads them at 2k,
and `textures convert` converts them to KTX2, a file format for compressed GPU
textures. The 1k and 512 versions are reduced copies. The source licences below
apply to these converted files.

Bark files are named `bark/<id>-<size>-<map>-<format>.ktx2`, and end-grain
files `end/<id>-<size>-<map>-<format>.ktx2`. The tables below list each
texture by its id.

Every texture is released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) (public
domain). Attribution is not required but is given as a courtesy.
